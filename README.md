A one-star review written by a house cat about the human it lives with —
one line, under 200 characters, deadpan real-review shape with an absurd
feline complaint. Entry for the make.fun bounty "Make the AI Judge Laugh:
Cat Reviews Its Human".

`main.py` is deterministic, uses no network, and writes the single review
line to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
